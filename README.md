# TASK-3
# E-Commerce Sales Analysis Using SQL

# Project Overview
This project focuses on analyzing an e-commerce database using SQL to explore sales data, customer behavior, and business performance. SQL queries are used to organize, retrieve, and analyze data to generate meaningful insights.

# Key SQL Concepts Used
- CREATE TABLE – Creating database tables.
- GROUP BY – Grouping data for analysis.
- Aggregate Functions – Using SUM(), COUNT(), AVG(), MIN(), and MAX().
- ORDER BY – Sorting data.
- WHERE and HAVING – Filtering records.
- JOIN – Combining data from multiple tables.

# Objective
The objective of this project is to strengthen SQL skills and gain practical experience in analyzing e-commerce data to support data-driven business decisions.

# Tools Used
- MySQL
- MySQL Workbench
- SQL

# Key Learning
Developed hands-on experience in database creation, data manipulation, and querying to extract meaningful business insights from e-commerce data.
